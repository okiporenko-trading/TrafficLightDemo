# TrafficLightDemo (iOS SwiftUI)

A simple iOS app built with SwiftUI that demonstrates a working traffic light.

## Run

1. Open `TrafficLightDemo.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Build and run.

## Features

- Three-light traffic signal (red, yellow, green)
- Manual `Next` step button
- Optional automatic cycling mode
